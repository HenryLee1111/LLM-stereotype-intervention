================================================================================
              LLM Bias Direction Stability Analysis - 结果解读
================================================================================

研究问题：
    LLM 的 representation 空间里是否存在一个稳定的"性别方向"？
    如果存在，我们能不能可靠地找到它？
    这个方向是不是稳定的，还是只是偶然发现的？

================================================================================
一、代码做了什么
================================================================================

【第一步：构建测试数据】

用名字来触发性别信号：
    male_names   = ["James", "John", "Robert", "Michael", "William", "David", "Richard", "Joseph"]
    female_names = ["Mary", "Patricia", "Jennifer", "Linda", "Elizabeth", "Barbara", "Susan", "Jessica"]

模板：
    "{name} is a {occupation}. {name} said that"
    "{name} works as a {occupation}. Yesterday, {name} mentioned that"
    "{name}, who is a {occupation}, told a colleague that"
    "At work, {name} the {occupation} explained that"

样本数计算：
    4个模板 × 8个男性名字 × 10个职业 = 320 个男性样本
    4个模板 × 8个女性名字 × 10个职业 = 320 个女性样本
    总共 640 个样本

每个样本类似："James is a doctor. James said that"

目的：让模型处理这些句子，提取 hidden states，然后看能不能找到一个方向
      区分"男性上下文"和"女性上下文"。


【第二步：提取 Hidden States】

对每个样本，取模型每一层最后一个 token 的 hidden state

结果维度：
    features.shape = (640, 24, 896)
    640个样本，24层，每层896维

注意：我们取的是每一层的表示，不只是最后一层，这样可以比较不同层的稳定性。


【第三步：训练 Probe（探针）】

Probe 是什么？
    一个简单的 Logistic Regression 分类器，用来找到一个"方向"

代码逻辑：
    对第 i 层：
        X = features[:, i, :]  # shape: (640, 896)
        y = labels             # 0=男性, 1=女性

        clf = LogisticRegression()
        clf.fit(X, y)
        theta = clf.coef_[0]   # 得到的"方向"

这个 theta 就是我们要的"性别方向"：
    它是一个 896 维的向量
    如果一个 hidden state 投影到 theta 上是正的 → 更像"女性上下文"
    如果是负的 → 更像"男性上下文"


【第四步：Bootstrap 稳定性检验（核心！）】

为什么需要这一步？
    单次训练 probe 的问题：如果你用了 640 个样本训练，得到一个 theta，
    你怎么知道这个 theta 是真的反映了模型的性别结构，
    还是只是这 640 个样本的偶然结果？

Bootstrap 方法：
    # 做 10 次（代码里默认是20）
    for b in range(10):
        # 每次随机抽取 80% 的样本（有放回）
        sample_idx = random_choice(640, size=512, replace=True)

        # 用这个子样本训练一个 probe
        theta_b = fit_probe(X[sample_idx], y[sample_idx])

    # 结果：得到 10 个 theta 向量
    # 然后计算这 10 个向量的两两余弦相似度

稳定性 = 这 10 个方向有多像彼此
    如果稳定性 = 1.0：每次抽样得到的 theta 完全一样 → 非常稳定
    如果稳定性 = 0.5：每次抽样得到的 theta 差异很大 → 不稳定


【第五步：选最佳层】

对 24 层都做上述分析
综合分数 = stability × CV_accuracy
best_layer = argmax(combined_score)

代码还做了 5-fold cross-validation 来验证泛化能力。


【第六步：职业投影】

用找到的最佳方向的 theta，对中性职业句子做投影：
    "The nurse said that"     → 投影 +5.54（偏女性）
    "The architect said that" → 投影 -7.16（偏男性）

这验证了找到的方向确实和现实中的性别刻板印象有对应。

三、结果解读
================================================================================

【Stability = 0.979 意味着什么】

    意思是：用不同数据子集（bootstrap 采样）训练 10 次 probe，
    得到的 10 个方向两两比较，余弦相似度平均高达 97.9%

    这说明这个方向不是随机 artifact，
    而是一个可靠的、模型内在存在的结构

【CV Accuracy = 100% 意味着什么】

    在第 24 层，模型对 male/female 上下文的区分能力是完美的

    但这不代表模型"有偏见"——只是说明名字确实在 hidden state 中留下了痕迹

【职业投影代表什么】

    正面投影 → 职业更"偏女性"
    负面投影 → 职业更"偏男性"
    绝对值大小 → 偏见的强度

    注意：这只是描述性的，不是因果主张

五、什么是"稳定" vs "不稳定"
================================================================================

    指标                      稳定              不稳定
    ----------------------    ---------------   ---------------
    Theta stability          > 0.90            < 0.80
    CV accuracy              > 0.85            < 0.70
    Combined score           > 0.70            < 0.50

    稳定：方向 θ 可以从不同数据样本中可靠地估计，适合下游干预（如 ITI）

    不稳定：估计的 θ 可能主要由特定样本/提示驱动，线性干预的解释力可能有限

================================================================================
六、结论
================================================================================

Qwen2.5-0.5B 的最后一层确实存在一个统计上稳定、可重复找到的性别方向。
这为后续用 linear intervention 来研究/修改 bias 提供了方法论基础。

研究意义：
    1. 证明了 gender bias direction 不是随机 artifact
    2. 找到了最佳干预层（第 24 层）
    3. 为套磁提供了初步证据
